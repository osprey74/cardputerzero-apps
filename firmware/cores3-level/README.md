# CoreS3 Level (IMU 水準器・傾斜計)

M5Stack CoreS3 (ESP32-S3) 用の**単体アプリ**。内蔵 6 軸 IMU (BMI270) の加速度から
傾き角を計算し、気泡水準器 / 傾斜計として表示する。CardputerZero 入力フロントエンド
([`../cores3-frontend`](../cores3-frontend)) とは独立した自己完結アプリ。

> 実機確定 (2026-06-24): CoreS3 フル版の内蔵 IMU は **BMI270**（磁気 BMM150 は非検出）。
> 加速度のみで傾き角を求めるため磁気は不要。

## モード (左右スワイプで切替 / 上部中央にモード名)

| モード | 基準面 | 用途 | 表示 |
| --- | --- | --- | --- |
| **FLAT** | 底面 (水平置き) | 机・棚など水平面の水平出し | 円形気泡水準器 + X/Y 角度 + `LEVEL` |
| **ANGLE** | 底面 | 面の傾斜・勾配の測定 | ROLL / PITCH 大表示 + 合成傾斜 (TILT) + 水平線 |
| **EDGE** | 手前側面 (縦置き) | 画面を垂直に立て、左右の鉛直 (倒れ) を見る | **下げ振り分銅** (固定点から赤い糸＋分銅が重力方向へ垂れる) |

- **FLAT / ANGLE** は底面 (Z 軸) を、**EDGE** は手前側面 (前後 Y 軸) を「下」の基準にする。
- **EDGE = 下げ振り (plumb bob)**: 画面上部の白 1px 水平線と左右中央の白 1px 垂直線の交点を
  固定点とし、そこから重力方向へ赤い糸 (1px) と分銅 (直径 約12px) が垂れる。本体の左右傾き
  (`edgeA`) につれて糸が固定点から振れ、**低い側へ垂れる**。本体が鉛直なら糸は中央の白線に
  重なる。`PLUMB ±x.x` に左右傾き角を表示 (鉛直時は緑)。測量/建築の下げ振りを画面内に再現。
  糸長 `L=150` (< 中央〜端 160px) のため真横 (±90°) まで端に触れず自由な円弧で振れる。

- **画面タップ** = 現在の姿勢をゼロ点に設定（相対測定・左上に `REL`）。再タップで解除（絶対表示に戻る）。
  - 基準面に置いてタップ → 測りたい面に移すと「基準からの相対角」が読める。
- **左右スワイプ** = モード切替。
- 許容範囲 (既定 ±0.5°) 内に入ると気泡・数値・水平線が緑になり、BUBBLE では `LEVEL` を表示。

## ⚠️ 軸の向きは実機で確認すること

BMI270 の取付け向き・符号は基板実装に依存する。初回書込み後、**液晶とシリアルログ
`{"log":"imu",...}` を見ながら**、傾けた向きと気泡/角度の動きが一致するか確認する。

逆に動く場合は [`src/main.cpp`](src/main.cpp) の以下の定数を `-1.0f` にする:

```cpp
static constexpr float ACC_SIGN_X = +1.0f;  // 左右が逆なら -1
static constexpr float ACC_SIGN_Y = +1.0f;  // 前後が逆なら -1
static constexpr float ACC_SIGN_Z = +1.0f;  // 上下が逆なら -1
```

水平置きで `az ≈ +1.0G`、右へ傾けると `angX` が +、手前へ傾けると `angY` が + に
なるのが基準。実機確定 (2026-06-30): `ACC_SIGN_Y = -1.0f`（前後が逆だったため反転）。

EDGE モードの平面 2 軸の符号は `EDGE_SIGN_A`（左右）/ `EDGE_SIGN_B`（手前/奥への倒れ）。
本体を手前側面で立て、傾けた向きと気泡が逆なら該当を `-1.0f` にする。

## 調整パラメータ ([`src/main.cpp`](src/main.cpp))

| 定数 | 既定 | 意味 |
| --- | --- | --- |
| `LEVEL_TOL_DEG` | `0.5` | 「水平」と判定する許容角 [deg] |
| `BUBBLE_FS_DEG` | `20.0` | 気泡が円の縁に達する傾き (フルスケール) [deg] |
| `ACCEL_ALPHA` | `0.20` | 加速度の平滑化係数 (小さいほど安定・遅い) |
| `DISPLAY_ROTATION` | `1` | 画面の向き (横 320×240) |

## ツールチェーン (PlatformIO)

```bash
pio run                # ビルド
pio run -t upload      # CoreS3 へ書込み (USB-C・既定 COM5)
pio device monitor     # 軸検証ログ {"log":"imu",...} を確認
```

`platform = espressif32` / `board = m5stack-cores3` / `framework = arduino`。依存は `M5Unified` のみ。
