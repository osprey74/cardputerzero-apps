# CoreS3 Seminar Timer (カウントダウン／経過時間計)

M5Stack CoreS3 (ESP32-S3) 用の**単体アプリ**。セミナー・登壇・作業時間の管理向けに、
プリセット時間 (90/120 分など) を選んで開始すると、円グラフ (ドーナツ) が **12 時位置から
時計回りに減少**していく。中央に**残り時間 (大)** と**経過時間 (小)** を併記する。
CardputerZero 入力フロントエンド ([`../cores3-frontend`](../cores3-frontend)) とは独立した自己完結アプリ。

## 画面と操作

| 状態 | 表示 | 操作 |
| --- | --- | --- |
| **SETUP** | プリセット時間を大きく表示 (`< 90 MIN >`) + 位置ドット | **左右スワイプ**=プリセット選択 / **タップ**=開始 |
| **RUNNING** | ドーナツ円グラフ + 中央に残り時間・経過時間 + 上部にプリセット名 | **タップ**=一時停止 / **下スワイプ**=リセット (SETUP へ) |
| **PAUSED** | 同上 (`PAUSED` を点滅) | **タップ**=再開 / **下スワイプ**=リセット |
| **DONE** | `TIME UP` 点滅 + 円は空 + 中央に超過時間 `+MM:SS` を赤で | **タップ / 下スワイプ**=SETUP へ戻る |

- **円グラフ**: 残り割合を弧で表す。時計回りに減っていく。全周が設定総時間。
- **残り時間**: 中央に大きく `MM:SS` (1 時間以上は `H:MM:SS`)。
- **経過時間**: その下に小さく `elapsed MM:SS`。
- **超過 (延長)**: 0 到達後は自動で **DONE** に入り、`TIME UP` を点滅させつつ超過時間を
  `+MM:SS` でカウントアップ（セミナーの巻き・延長把握用）。
- **一時停止**: PAUSED 中は経過・残りとも凍結し、再開時に停止分を差し引く（正確な計時）。

## 配色 (残り割合で変化)

| 残り割合 | 色 | 意味 |
| --- | --- | --- |
| > 25% | グリーン | 余裕あり |
| 10〜25% | オレンジ | 残りわずか |
| ≤ 10% | 赤 | 僅少 |
| 残り 10 秒以内 | 赤 (弧が点滅) | 直前警告 |
| 超過 (0 未満) | 赤 (`TIME UP` 点滅) | 延長中 |

## プリセット / 永続化

- プリセット (分): `5 / 15 / 30 / 45 / 60 / 90 / 120`（既定 **90 分**）。
- 変更するには [`src/main.cpp`](src/main.cpp) の `PRESET_MIN[]` を編集する。
- 最後に選んだプリセットは **NVS (Preferences)** に保存し、次回起動時に復元する。

## 調整パラメータ ([`src/main.cpp`](src/main.cpp))

| 定数 | 既定 | 意味 |
| --- | --- | --- |
| `PRESET_MIN[]` | `{5,15,30,45,60,90,120}` | 選択できるプリセット時間 [分] |
| `PRESET_DEFAULT` | `5` | 既定プリセットのインデックス (= 90 分) |
| `SWIPE_THRESHOLD` | `50` | スワイプと判定する移動量 [px] |
| `TAP_MAX_MOVE` | `16` | タップと判定する最大移動量 [px] |
| `DISPLAY_ROTATION` | `1` | 画面の向き (横 320×240) |

## ツールチェーン (PlatformIO)

```bash
pio run                # ビルド
pio run -t upload      # CoreS3 へ書込み (USB-C・既定 COM5)
pio device monitor     # 起動ログ {"log":"init",...} を確認
```

`platform = espressif32` / `board = m5stack-cores3` / `framework = arduino`。依存は `M5Unified` のみ。
